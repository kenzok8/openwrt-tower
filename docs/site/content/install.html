安装与升级

Tower 由两个包组成：tower 是后端程序和内置规则，luci-app-tower 是 LuCI 界面。两个都装完，才能在「服务 → Tower」里看到入口。

一键安装

在路由器上以 root 执行。脚本会接入现有的 dllkids 软件源，再按固件版本用 apk 或 opkg 装包：

wget -O - https://raw.githubusercontent.com/kenzok8/openwrt-tower/main/scripts/install.sh | sh

安装完成后刷新 LuCI 页面即可。如果脚本报找不到源，检查设备能不能访问 down.dllkids.xyz。

通过软件源安装

已经接入该软件源的设备，不需要再跑脚本：

# 25.12 / apk
apk update && apk add tower luci-app-tower

# 24.10 / opkg
opkg update && opkg install tower luci-app-tower

用 SDK 自己编译

把仓库当作 src-link feed 接入已配置好 Go 环境的 SDK：

echo 'src-link tower /absolute/path/to/openwrt-tower' >> feeds.conf
./scripts/feeds update -a
./scripts/feeds install -p tower tower luci-app-tower
make package/tower/compile V=s
make package/luci-app-tower/compile V=s

tower 是 Go 程序，交叉编译需要 SDK 自带 Go 工具链；luci-app-tower 是纯 LuCI 资源，架构无关。

从 Release 手动安装

到 Releases 下载与你的系统版本、架构匹配的两个包：

  • 24.10 用 .ipk，opkg install
  • 25.12 用 .apk，需要 apk add --allow-untrusted（Release 的 apk 未签名）

设备上已有可信软件源时，优先走软件源安装，升级能跟上源里的版本。

升级与备份

升级只覆盖程序和界面，你的数据原样保留：

  • /etc/config/tower —— UCI 配置，属于 conffiles，升级不会覆盖你的修改
  • /etc/tower/tower.json —— 订阅、节点、规则方案的私有状态
  • /etc/tower/rule-cache/ —— 远程规则集缓存

升级前建议先备份这四处（含 /etc/config/tower）。回滚时把两个包降到旧版本，再把备份放回去即可。

升级后如果界面还是旧样子，浏览器强制刷新一次；LuCI 会缓存静态资源。

卸载

apk del luci-app-tower tower        # 25.12
opkg remove luci-app-tower tower    # 24.10

卸载不会自动删 /etc/tower/。确认不再使用后手动删除，否则下次安装会直接接上旧数据。
