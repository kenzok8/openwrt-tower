常见问题

按「现象 → 先查什么」的顺序排。改动配置前建议先备份 /etc/tower/tower.json。

装完了但 LuCI 里看不到 Tower

  • 确认两个包都装了：apk list --installed | grep tower
  • 清一次 LuCI 缓存：删除 /tmp/luci-indexcache 后刷新页面
  • 确认当前用户有 luci-app-tower 的 ACL 权限

生成的配置导入后被插件拒绝

先看插件自己的日志，Tower 只保证格式对得上，不保证目标插件接受全部参数：

  • Mihomo 系：多半是某条规则集地址拉不到，或某个协议参数超出版本支持
  • sing-box：检查是否有「不支持的规则」提示，Tower 的规则方案还不能等价转成 sing-box 分流
  • dae / Honk：模板里的网卡名（如 br-lan）必须和设备实际网卡一致

本机订阅地址拉不到

  • 地址必须是 http://127.0.0.1:7443/...，换机器或换成 LAN IP 都不行，服务只监听回环
  • 确认后端在跑：pgrep -f 'tower'，或重启服务后再试
  • token 可能已被吊销，回「导出」页重新生成分享地址

订阅更新失败

  • 先在设备上用 wget 直接拉一次订阅链接，排除网络和 DNS 问题
  • 有些机场按 User-Agent 返回不同格式，试着换一个 UA 再更新
  • 更新失败不会清空已有节点，旧数据还在

我的设备架构能用吗

看 Release 里有没有对应架构的包。SDK 25.12 不含 mips_4kec；只做了编译验证的架构，实际运行效果需要你自己确认。真机验证目前只有 x86_64 + 25.12。

想从零开始

/etc/init.d/tower stop
rm -rf /etc/tower
/etc/init.d/tower start

这会清掉订阅、节点和规则方案，/etc/config/tower 里的端口设置保留。
