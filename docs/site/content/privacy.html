隐私与数据

Tower 的所有处理都在路由器本地完成：订阅解析、规则合并、配置生成都不经过第三方服务。

数据放在哪

路径内容
/etc/config/towerUCI 配置：监听端口、分享开关等，属于包 conffiles
/etc/tower/tower.json订阅链接、节点、规则方案、分享 token 等私有状态
/etc/tower/rule-cache/下载回来的规则集缓存，可随时删除

这些文件只在本机读走，Tower 不向外发送。备份时注意：tower.json 里有订阅凭据和节点密码，别随手贴到公开的地方。

会连哪些地址

  • 你自己填的订阅地址和规则集地址
  • 内置方案里引用的公开规则集（首次刷新时下载，之后走缓存）
  • 更新检查会访问 GitHub Releases（只读取版本信息）

除此之外没有遥测、没有统计上报、没有「云端转换」。

本机订阅的安全边界

  • 后端只监听 127.0.0.1，启动时如果监听地址不是回环，程序会直接退出
  • 分享地址带随机 token，可以随时吊销
  • 响应带 Cache-Control: no-store 和 X-Content-Type-Options: nosniff
  • 管理操作走 LuCI 的 rpcd，不经过这个 HTTP 服务

彻底清除

apk del luci-app-tower tower          # 或 opkg remove
rm -rf /etc/tower /etc/config/tower   # 数据要手动删

卸载脚本不会自动删 /etc/tower/，避免误删你的订阅。确认不再使用后再手动清理。
